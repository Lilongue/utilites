## В двух словах

Личный офлайн-каталог книг (пакет `booklibrary` в репозитории `utilites`).
Два сценария, ради которых всё делается:

1. **«Где эта книга?»** — быстро найти на диске файл нужной книги и открыть его.
2. **«Что я отметил при чтении?»** — заметки/цитаты привязаны к книге, ищутся
   вместе с ней и не теряются при переезде файлов.

Один пользователь, Windows, без сервера и без синхронизации между устройствами
(последнее — допущение, требует подтверждения).

## Соглашения о работе

1. **Сначала требования** (user stories и сценарии), потом план, потом код.
2. Код — маленькими вертикальными шагами: один шаг = один коммит = зелёные
   тесты = diff на просмотр. Без «больших заходов».
3. `master` не трогаем: работа в отдельной ветке, коммиты только после «ок».
4. Большие решения (архитектура, интерфейс, хранение) — только с подтверждением.
5. Старый код не удаляем и не переносим без отдельного согласования; сначала
   новый сценарий должен заработать на реальных данных.
6. Не додумывать требования молча: непонятное — вопрос, а не допущение.

## Глоссарий

- **Книга** — логическая сущность (название + автор), может иметь несколько файлов.
- **Файл** — конкретный файл на диске (pdf, fb2, djvu…), путь и признак «нет на диске».
- **Заметка** — текст пользователя, привязанный к книге (возможно, к странице/главе).
- **Полка** — состояние чтения: хочу / читаю / прочитано / брошено.
